# Open Source SaaS Platform

## Overview

This repository provides the initial monorepo foundation for an open-source SaaS platform. It is intentionally limited to project scaffolding so the backend, frontend, and documentation can evolve independently without introducing application logic yet.

## Technology Stack

- Frontend: Next.js (planned, not initialized yet)
- Backend: FastAPI (planned, not initialized yet)
- Documentation: Markdown-based docs
- Local infrastructure: Docker Compose
